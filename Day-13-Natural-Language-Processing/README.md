# Day 13 – Natural Language Processing (NLP)

## Objective

Learn basic text preprocessing techniques and convert text into numerical features using TF-IDF.

## Dataset

A small dataset of 8 sample customer reviews containing positive and negative feedback.

## Techniques Implemented

- Lowercasing
- Tokenization using NLTK
- Stopword Removal
- TF-IDF Vectorization
- Identification of high-scoring words
- Exporting TF-IDF output to CSV

## Libraries Used

- Python
- Pandas
- NLTK
- Scikit-learn

## Deliverables

- NLP_Practice.ipynb
- TF-IDF_Output.csv

## Conclusion

This task demonstrated how raw text can be cleaned, tokenized, and transformed into numerical features using TF-IDF. These preprocessing techniques are useful in text classification, sentiment analysis, and other NLP applications.
