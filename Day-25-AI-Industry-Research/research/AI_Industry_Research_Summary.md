## 1. Introduction

Artificial Intelligence is rapidly changing how businesses build software, automate tasks, analyze data, and interact with customers.

Modern AI applications increasingly use Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and AI agents. However, building an AI application is not only about getting a model to generate an answer. Developers must also consider cost, speed, reliability, scalability, and accuracy.

This research explores three important areas of the AI industry.

## 2. Topic One – Latest AI Trends

Some important AI trends include:

### Generative AI

Generative AI creates new content such as text, images, code, and summaries based on user instructions.

### AI Agents

AI agents can understand a task, plan multiple steps, use tools, and perform actions with limited human intervention.

### Retrieval-Augmented Generation (RAG)

RAG retrieves relevant information from documents or databases and provides it as context to an LLM before generating an answer.

### Multimodal AI

Multimodal AI systems can work with different types of information, including text, images, audio, and video.

**Business impact:**

- Automates repetitive business activities.
- Improves customer support.
- Helps employees retrieve information faster.
- Supports decision-making and productivity.
- Enables more personalized services.

## 3. Topic Two – AI Cost Optimization

AI applications often use APIs that charge based on token consumption.

A token is a small unit of text processed by an AI model. API usage commonly includes:

- Input tokens: Text sent to the model.
- Output tokens: Text generated by the model.

### Why cost optimization matters

As applications become more complex, they may send larger prompts, generate longer responses, and make multiple model calls.

Developers can optimize costs through:

1. Prompt optimization – Remove unnecessary instructions and repeated context.
2. Model selection – Use smaller, less expensive models for simple tasks.
3. Token management – Limit input size and output length.
4. Model routing – Select a model based on task complexity.
5. Caching – Reuse previously generated results when appropriate.
6. Usage monitoring – Track API requests, tokens, latency, and cost.

**Business impact:**

Cost optimization helps organizations reduce operational expenses while maintaining acceptable application quality and performance.

## 4. Topic Three – Production AI

Production AI means deploying an AI application so that real users can access and use it reliably.

A successful AI prototype is not automatically production-ready.

Important production requirements include:

- API integration and secure key management.
- Error handling and retry mechanisms.
- Input validation.
- Logging and monitoring.
- Response-time measurement.
- Scalability and availability.
- Security and data privacy.
- Evaluation of model responses.

**Example:**

An AI customer-support assistant should not simply generate answers. It should also handle unavailable APIs, monitor response times, protect customer data, and provide reliable responses.

## 6. Mini Practical – AI Provider Comparison

The practical experiment compared four AI providers:

1. OpenAI
2. Claude
3. Gemini
4. Groq

Three common questions were used to evaluate provider responses:

- Difference between Python lists and tuples.
- Meaning of HTTP status code 404.
- Explanation of Retrieval-Augmented Generation.

### Observed results

| Provider | Test outcome       | Observation                          |
| -------- | ------------------ | ------------------------------------ |
| OpenAI   | Unavailable        | API account had no remaining credits |
| Claude   | Unavailable        | Insufficient API credit balance      |
| Gemini   | Unavailable        | Temporary 503 service errors         |
| Groq     | Responses received | All three requests completed         |

### Groq observations from the latest run

- Average response latency: 1.24 seconds.
- Average keyword score: 50%.
- Successful requests recorded: 3.
- Input and output token usage recorded in the CSV file.

Note: A completed API request does not necessarily mean the answer is correct. The keyword score is a simple evaluation method, not a complete accuracy measurement. The RAG response was empty in the latest run, so its quality requires further testing.

The comparison was limited by API credit availability and temporary service errors. Therefore, a complete cost, speed, and accuracy ranking across all four providers could not be established.

## 7. Key Learning Points

1. AI technology is moving beyond basic chatbots toward agentic systems.
2. Token usage directly affects API operating costs.
3. Choosing the correct model is important for cost and performance.
4. Production AI requires reliability, monitoring, security, and error handling.
5. API response time and response quality should be evaluated separately.
6. Developers should understand multiple AI providers and their APIs.
7. AI applications need continuous testing and improvement.
