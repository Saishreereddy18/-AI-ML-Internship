# Day 12 – Model Evaluation in Machine Learning

## Objective
Evaluate classification models using standard machine learning metrics.

## Dataset
Breast Cancer Wisconsin dataset from Scikit-learn.

## Models Evaluated
- Logistic Regression
- Decision Tree Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Deliverables
- `Model_Evaluation.ipynb` – evaluation notebook
- `confusion_matrix.png` – confusion matrix visualization
- `performance_report.txt` – model performance and conclusions

## Key Learning
Accuracy measures overall correctness, while precision and recall measure different types of prediction performance. F1-score balances precision and recall.

For breast cancer classification, recall for the malignant class is particularly important because false-negative predictions can have serious consequences.

## Tools Used
Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook, Git and GitHub.
