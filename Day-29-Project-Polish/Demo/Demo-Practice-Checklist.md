\# AI Career Copilot – Demo Practice Checklist



\## 1. Application Setup

\- \[ ] Activate virtual environment.

\- \[ ] Install required dependencies.

\- \[ ] Configure environment variables.

\- \[ ] Start FastAPI backend.

\- \[ ] Start Streamlit frontend.

\- \[ ] Verify application is running.



\## 2. Live Demo

\- \[ ] Introduce the project.

\- \[ ] Show the home page.

\- \[ ] Upload a sample resume.

\- \[ ] Demonstrate resume processing.

\- \[ ] Show job recommendations.

\- \[ ] Demonstrate skill gap analysis.

\- \[ ] Show tailored resume generation.

\- \[ ] Show cover letter generation.

\- \[ ] Demonstrate application tracking.



\## 3. Technical Demonstration

\- \[ ] Explain frontend and backend.

\- \[ ] Explain API integration.

\- \[ ] Explain RAG workflow.

\- \[ ] Explain LangGraph agents.

\- \[ ] Explain document processing.

\- \[ ] Demonstrate error handling.



\## 4. Final Verification

\- \[ ] Check all application features.

\- \[ ] Verify API responses.

\- \[ ] Check terminal for errors.

\- \[ ] Keep sample resume ready.

\- \[ ] Prepare backup screenshots.

\- \[ ] Practice the complete demo.



\## 5. Presentation Timing

\- Introduction: 1 minute

\- Problem statement: 1 minute

\- Architecture: 2 minutes

\- Features: 3 minutes

\- Live demo: 5 minutes

\- Challenges and future improvements: 2 minutes

\- Questions: 1 minute



Total: 15 minutes
