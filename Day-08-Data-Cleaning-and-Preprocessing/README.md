# Day 8 – Data Cleaning and Preprocessing

## Objective

To understand the importance of data cleaning and preprocessing using Python and Pandas.

## Tasks Completed

- Created and loaded a sample student dataset.
- Identified missing values and duplicate rows.
- Cleaned column names by removing extra spaces.
- Converted Age and Marks columns into numeric data types.
- Handled missing numerical values using the median.
- Filled missing department values using the mode.
- Removed duplicate records.
- Saved the cleaned dataset as a CSV file.

## Tools and Libraries

- Python
- Pandas
- Jupyter Notebook
- CSV files

## Files Included

- `data_cleaning.ipynb` – Notebook containing the data cleaning steps.
- `student_data_raw.csv` – Original dataset.
- `cleaned_student_data.csv` – Cleaned dataset.

## Outcome

Successfully practiced basic data cleaning techniques and generated a cleaned dataset with missing values and duplicate records handled.
