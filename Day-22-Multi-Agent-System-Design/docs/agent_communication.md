# Agent Communication and Shared State

## Day 22 – Multi-Agent System Design

### 1. Introduction

Agent communication is the process through which multiple AI agents exchange information, share results and coordinate their activities to complete a common objective.

In the AI Research Assistant, five specialized agents communicate through a Coordinator Agent and a shared state.

### 2. Communication Methods

**1. Direct Communication**

One agent sends its output directly to another agent.

Example: Research Agent sends collected findings to the Analyzer Agent.

**2. Coordinator-Based Communication**

The Coordinator Agent manages communication and assigns tasks to different agents.

Example: Coordinator sends a research request to the Research Agent.

**3. Shared State Communication**

Agents read and update a common state containing task information and intermediate results.

Example: Analyzer stores its analysis results in the shared state for the Critic Agent.

### 3. Message Structure

Each agent communication message can contain:

| Field        | Description                  |
| ------------ | ---------------------------- |
| sender       | Agent sending the message    |
| receiver     | Agent receiving the message  |
| task_id      | Unique task identifier       |
| message_type | Request, result or feedback  |
| content      | Actual message information   |
| status       | Pending, completed or failed |

### 4. Agent Communication Flow

1. Coordinator sends a task to Research Agent.
2. Research Agent collects information and shares findings.
3. Analyzer receives the findings and produces insights.
4. Critic reviews the findings and analysis.
5. Critic sends feedback if corrections are necessary.
6. Writer receives validated information.
7. Writer generates the final report.
8. Coordinator delivers the result.

### 5. Shared State Management

Shared state is a common data structure used to store information throughout the workflow.

It allows agents to access relevant information generated by previous agents.

**Important Shared State Variables:**

- research_query
- research_findings
- analysis_results
- critic_feedback
- validation_status
- final_report
- workflow_status
- retry_count

### 6. Example Shared State

```python
shared_state = {
    "research_query": "Applications of Generative AI",
    "research_findings": [],
    "analysis_results": {},
    "critic_feedback": [],
    "validation_status": "pending",
    "final_report": "",
    "workflow_status": "research",
    "retry_count": 0
}
```

### 7. State Update Process

Each agent updates only the information related to its responsibility.

- Research Agent updates research_findings.
- Analyzer Agent updates analysis_results.
- Critic Agent updates critic_feedback and validation_status.
- Writer Agent updates final_report.
- Coordinator Agent updates workflow_status and retry_count.

In a real implementation, state updates should be managed carefully to avoid conflicting changes.

### 8. Communication Rules

- Every agent should have a clearly defined responsibility.
- Messages should contain relevant task information.
- Agents should use structured outputs.
- Failed tasks should be reported to the Coordinator.
- Shared state should maintain the latest valid information.
- The system should avoid unnecessary repeated communication.

### 9. Connection with LangGraph

LangGraph is a framework for building stateful, multi-step AI agent workflows.

Important concepts:

- Nodes: Individual agents or processing steps.
- Edges: Connections between agents.
- State: Shared information passed through the workflow.
- Conditional Edges: Routing based on decisions or validation results.
- Checkpointing: Saving workflow state for recovery and continuation.

### 10. Conclusion

Agent communication and shared state management enable multiple AI agents to collaborate effectively. Structured messages, clear responsibilities and controlled state updates make the overall workflow easier to manage, monitor and maintain.
