# Day 23 – Agent Communication Flow Document

## 1. Project Overview

Project Name: Complete Multi-Agent System Using LangGraph

The system consists of five specialized agents that work together to process a user request and generate a final response.

LangGraph is used to manage agent execution, shared state, conditional routing and workflow termination.

## 2. System Architecture

The system follows this execution flow:

User Request
|
v
Coordinator Agent
|
v
Research Agent
|
v
Analyzer Agent
|
v
Critic Agent
|
|---- Approved ----> Writer Agent ----> Final Answer
|
|---- Rejected -----> Analyzer Agent (Retry)
|
|---- Retry Limit Reached ----> Stop

## 3. Agent Responsibilities

### 3.1 Coordinator Agent

Input:

- User query

Processing:

- Receives the user request.
- Identifies the question.
- Updates the current agent information.

Output:

- User query
- Current agent status

### 3.2 Research Agent

Input:

- User query

Processing:

- Searches a predefined local knowledge base.
- Identifies relevant information.

Output:

- Research findings
- Current agent status

### 3.3 Analyzer Agent

Input:

- Research findings

Processing:

- Checks whether research information is available.
- Generates an analysis summary.
- Identifies key insights, benefits and applications.

Output:

- Analysis
- Error information, if applicable

### 3.4 Critic Agent

Input:

- Analysis generated by the Analyzer.

Processing:

- Checks whether required sections are available.
- Reviews the analysis.
- Approves or rejects the result.
- Updates retry count when rejected.

Output:

- Critic feedback
- Approval status
- Retry count

### 3.5 Writer Agent

Input:

- Approved analysis
- Critic feedback
- Original user query

Processing:

- Generates the final response.
- Includes the analysis and review status.

Output:

- Final answer

## 4. Shared State Management

All agents communicate through a shared state structure defined using Python TypedDict.

The shared state contains:

| Field           | Purpose                  |
| --------------- | ------------------------ |
| user_query      | Original user request    |
| research_data   | Research findings        |
| analysis        | Analyzer output          |
| critic_feedback | Critic review            |
| final_answer    | Final generated response |
| current_agent   | Tracks active agent      |
| errors          | Stores error messages    |
| retry_count     | Tracks retry attempts    |
| approved        | Stores approval status   |

## 5. Agent Communication Mechanism

LangGraph manages communication between agents through a shared state.

Each agent:

1. Receives the current state.
2. Processes its assigned task.
3. Returns updated state fields.
4. Passes control to the next workflow node.

Conditional routing is used after the Critic Agent.

If approved:
The workflow moves to the Writer Agent.

If rejected:
The workflow can return to the Analyzer Agent, subject to the retry limit.

If analysis is empty:
The workflow stops.

## 6. Error Handling

The system handles the following conditions:

- Missing research information.
- Empty analysis.
- Critic rejection.
- Maximum retry limit.

Errors are stored in the shared state for tracking.
