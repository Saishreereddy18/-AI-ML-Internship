# PERSONAL LEARNING ROADMAP – 90 DAYS

**Career Goal:** AI Engineer / AI Developer

## Month 1 – Fundamentals & Problem Solving

- Strengthen Python programming.
- Practice Data Structures and Algorithms.
- Improve SQL and database concepts.
- Revise Machine Learning fundamentals.
- Solve coding problems regularly.

## Month 2 – Advanced AI & Projects

- Learn Deep Learning fundamentals.
- Explore Generative AI and LLMs.
- Improve RAG, embeddings and vector databases.
- Practice LangChain, LangGraph and FastAPI.
- Build one practical AI project.

## Month 3 – Career Preparation

- Explore advanced AI Agent development.
- Improve existing GitHub projects.
- Practice technical and HR interviews.
- Revise Python, SQL, ML and DSA.
- Update resume, LinkedIn and portfolio.
- Apply for AI/ML internships and fresher opportunities.

## Expected Outcomes

- Stronger programming and problem-solving skills.
- Better understanding of AI and ML technologies.
- At least one additional practical AI project.
- Improved interview confidence.
- Job-ready resume and portfolio.

**Final Goal:** Become confident in developing practical AI applications and prepare for entry-level AI Engineer opportunities.
