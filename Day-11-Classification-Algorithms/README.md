# Day 11 – Classification Algorithms

## Objective

Understand classification problems and train and compare two machine learning models.

## Dataset

Breast Cancer Wisconsin dataset from Scikit-learn.

- Total records: 569
- Features: 30
- Target classes: Benign and Malignant

## Algorithms Used

1. Logistic Regression
2. Decision Tree Classifier

## Tasks Completed

- Loaded and explored the dataset.
- Checked for missing values.
- Split the data into training and testing sets.
- Applied feature scaling for Logistic Regression.
- Trained both classification models.
- Compared model accuracy using a table and bar chart.
- Evaluated models using precision, recall, and F1-score.
- Recorded observations.

## Technologies Used

Python, Pandas, Matplotlib, Scikit-learn, Jupyter Notebook.

## Result

Both models were trained and evaluated on the same test dataset. The notebook compares their accuracy and identifies the model with the higher test accuracy.

## Learning Outcome

Learned the fundamentals of classification, model training, predictions, evaluation metrics, and model comparison.

**Note:** This is an educational machine learning project and is not intended for medical diagnosis.
