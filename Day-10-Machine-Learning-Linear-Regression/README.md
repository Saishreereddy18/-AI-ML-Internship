# Day 10 – Machine Learning Fundamentals

## Student Marks Prediction Using Linear Regression

### Overview

This project demonstrates the basic Machine Learning workflow using Python and Scikit-learn. A Linear Regression model is trained to predict student marks based on the number of study hours.

### Objectives

- Understand the basic Machine Learning workflow.
- Create and explore a sample dataset.
- Split the dataset into training and testing sets.
- Train a Linear Regression model.
- Predict student marks.
- Evaluate model performance.
- Save the trained model and prediction results.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Jupyter Notebook

### Machine Learning Workflow

1. Import the required libraries.
2. Create a sample student marks dataset.
3. Visualize the relationship between study hours and marks.
4. Separate input features and target values.
5. Split the data into training and testing sets.
6. Train the Linear Regression model.
7. Generate predictions.
8. Evaluate the model using MAE, MSE, RMSE and R² score.
9. Save the trained model and prediction results.
10. Load the saved model and test a new prediction.

### Project Files

- `ML_Practice.ipynb` – Notebook containing the code, visualizations and results.
- `linear_regression_model.pkl` – Saved, trained Linear Regression model.
- `prediction_results.csv` – Actual and predicted marks for test data.
- `README.md` – Project documentation.

### Conclusion

This project provided practical experience with supervised Machine Learning, data preprocessing basics, training and testing data, Linear Regression, predictions, model evaluation and model saving.

**Note:** This project uses a small sample dataset for educational purposes. Its results are intended to demonstrate the workflow and are not a real-world student performance assessment.
