# Day 9 – Exploratory Data Analysis (EDA)

## Objective
To explore the cleaned student dataset, calculate descriptive statistics, identify patterns, and visualize student performance using Python.

## Dataset
- Source: Day 8 – Data Cleaning and Preprocessing
- File: `cleaned_student_data.csv`
- Columns: Student Name, Age, Marks, Department

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Completed
- Loaded the cleaned dataset.
- Inspected dataset dimensions, columns, and data types.
- Checked missing values and duplicate records.
- Calculated descriptive statistics.
- Analyzed student performance by department.
- Created five data visualizations.
- Examined patterns and prepared business insights.

## Visualizations
1. Distribution of Student Marks
2. Spread of Student Marks
3. Average Marks by Department
4. Number of Students by Department
5. Relationship Between Age and Marks

## Business Insights
Insights will be documented based on the actual statistical results and visualizations.

## Deliverables
- `EDA_Student_Performance.ipynb`
- `README.md`
- Five visualizations displayed in the notebook
- Five data-driven business insights

## Outcome
Practiced exploratory data analysis and learned how statistics and visualizations can support data-driven decisions.
