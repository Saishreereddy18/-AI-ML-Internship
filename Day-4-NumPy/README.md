## ⚖️ Python List vs NumPy Array

Python Lists are general-purpose data structures, while NumPy Arrays are specifically designed for efficient numerical and mathematical operations.

For example:

```python
python_list = [10, 20, 30]
numpy_array = np.array([10, 20, 30])

print(python_list * 2)
print(numpy_array * 2)
```

NumPy allows mathematical operations to be performed directly on array elements.
