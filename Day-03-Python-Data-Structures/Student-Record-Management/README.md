# Student Record Management System

## Project Overview

The Student Record Management System is a simple Python console application used to store, view, and search student records.

Student information is stored in a text file named `students.txt`.

## Features

- Add Student
- View Students
- Search Student by Roll Number
- Exit the application
- Store student records in a text file

## Student Details

The system stores:

- Roll Number
- Name
- Branch
- Marks

## Technologies Used

- Python
- File Handling
- Dictionaries
- Lists
- VS Code

## How to Run

Open the terminal inside the `Student-Record-Management` folder and run:

```bash
python student_management.py
```
