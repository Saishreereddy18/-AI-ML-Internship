# Day 6 – Python Data Visualization

## 🎯 Learning Objectives

- Understand the importance of data visualization.
- Learn to represent data using different types of charts.
- Practice creating visualizations using Matplotlib and Seaborn.
- Analyze data and identify useful observations from charts.

## 🛠️ Tools and Libraries Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## 📊 Dataset

For this task, I reused the student dataset from Day 5. It contains student information such as Student ID, Name, Age, Gender, Marks, and Attendance.

## 💻 Tasks Performed

### 1. Imported Libraries

Imported Pandas, Matplotlib, and Seaborn to load, analyze, and visualize the dataset.

### 2. Loaded the Dataset

Loaded the existing CSV dataset using Pandas and displayed the first five records to understand its structure.

### 3. Explored the Dataset

Checked the dataset information, column names, missing values, and statistical summary before creating visualizations.

### 4. Created a Bar Chart

Used Seaborn to compare the marks of different students and understand differences in their performance.

### 5. Created a Line Chart

Used Seaborn to visualize how student marks vary across student IDs.

### 6. Created a Histogram

Used Seaborn to understand the distribution of student marks and identify the ranges in which students' scores are concentrated.

### 7. Created a Pie Chart

Used Matplotlib to represent the gender distribution of students as percentages.

### 8. Analyzed the Results

Used the charts and basic statistical calculations to identify the highest marks, lowest marks, average marks, and gender counts. Recorded observations based on the dataset.

## 📌 Key Learnings

- Understood why data visualization is useful for exploring and communicating data.
- Learned how to create bar charts, line charts, histograms, and pie charts.
- Practiced adding chart titles, axis labels, markers, and percentage labels.
- Learned to customize chart appearance using Seaborn themes.
- Understood how visualizations help identify patterns, compare values, and understand distributions.
