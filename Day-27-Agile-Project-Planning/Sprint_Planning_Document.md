# Day 27 – Sprint Planning Document

## Project Name

AI Career Copilot – AI-Powered Job Recommendation System

## Project Objective

To develop an AI-based application that analyzes resumes, recommends suitable job opportunities, identifies skill gaps, and generates customized resumes and cover letters.

## Methodology

Agile Methodology – The project is divided into smaller development cycles called Sprints.

## Sprint Plan

| Sprint   | Activities                                | Complexity |
| -------- | ----------------------------------------- | ---------- |
| Sprint 1 | Requirement analysis and project planning | Medium     |
| Sprint 2 | Resume upload and text extraction         | Medium     |
| Sprint 3 | Resume parsing and skill extraction       | High       |
| Sprint 4 | Job API integration                       | High       |
| Sprint 5 | AI-based job matching                     | High       |
| Sprint 6 | Skill gap analysis                        | Medium     |
| Sprint 7 | Resume and cover letter generation        | High       |
| Sprint 8 | Frontend integration and testing          | High       |
| Sprint 9 | Deployment and documentation              | Medium     |

## Expected Outcome

A functional AI-powered career assistance platform that helps users identify suitable jobs and improve their applications.
